# GlassUsage v0.7.13

## Windows mini-card fix

- Fix background sliding or trailing behind the mini card while dragging.
- Keep refraction and chromatic dispersion active throughout the gesture.
- Render card placement and desktop sampling in the same Flutter frame using a fixed transparent host.
- Preserve click-through outside the rounded card, foreground contrast adjustment, and fresh capture after hide/resume.

## Validation

Windows Debug builds and targeted analysis passed. Automated drag measurements
found no background-edge displacement in 770 changed-position images with
4,043 measurable interior edges. Live background capture, external/corner input
passthrough, and hide/resume were also checked. The user confirmed normal
background dragging with the optical effects preserved.

Multi-monitor and mixed-DPI behavior has not been validated in this release's
manual test setup. Local composition results are not end-to-end latency measurements.

## Install / upgrade

- Installer: **GlassUsage_0.7.13_x64-setup.exe**.
- Portable: extract **GlassUsage_0.7.13_windows_x64_portable.zip** and run **glassusage.exe**.
- Existing installations can check for updates in Settings.
- **SHA256SUMS.txt** contains the installer and portable archive checksums.
