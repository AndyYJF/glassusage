# GlassUsage v0.7.14

## Version display and update checks

- Show the version of the actual build instead of the hard-coded 0.7.11 label.
- Use the same build version when checking for updates, preventing repeated offers to reinstall an already-installed release.
- The value is injected by Flutter from pubspec.yaml or the build-name override; future releases no longer need a separate UI version edit.
- Includes the Windows mini-card background dragging fix from v0.7.13, with refraction and dispersion preserved.

## Install / upgrade

- Installer: **GlassUsage_0.7.14_x64-setup.exe**.
- Portable: extract **GlassUsage_0.7.14_windows_x64_portable.zip** and run **glassusage.exe**.
- Existing application data and settings are retained during upgrade.
- **SHA256SUMS.txt** contains the installer and portable archive checksums.
